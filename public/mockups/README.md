## Screenshot guidance

- Use **PNG or WebP** exports from the app. Keep text at 1x or 2x; avoid
  upscaling.
- Phone frames are rendered around the image, so export the **screen only** —
  no device bezel, notch or status bar needed.
- Desktop screenshots are displayed inside a browser frame. Export the app
  viewport only (no browser chrome).
- Keep each file under ~400 KB if possible (they are served as static assets).

The screenshots use the light theme. To refresh them, sign in to the local
workspace, open the module route, and capture at the sizes above.
